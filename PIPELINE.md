# Automated Papercraft Pipeline (`papikapi-studio`)

Deterministic 2-stage generative pipeline that turns a text prompt and optional reference photos into an axonometric papercraft design (Stage 0) and synthesizes a production-ready 3D model (Stage 1).

---

## 🏛️ Architecture Overview

The pipeline is implemented entirely in strict **TypeScript (`.ts`)** under Node 24 with `tsx`, abandoning all legacy Python scripts and ad-hoc `.mjs` utilities. Every module follows the **Single Responsibility Principle (SRP)** and object-oriented design:

```text
apps/papikapi-studio/
├── pipeline.json                 # 100% configurable single source of truth
├── resources/                    # Development working area (per model)
│   └── [model]/
│       ├── stage-0/
│       │   ├── step-1-alternatives.jpeg  # 3x2 grid with 6 style variations
│       │   ├── step-1-manifest.json      # Gemini API timing & cost manifest
│       │   ├── step-1-art.jpeg           # Selected cell cropped at high-res
│       │   └── step-2-manifest.json      # Selection record
│       └── stage-1/
│           ├── step-1-3d.glb             # 3D GLB mesh generated by TRELLIS
│           └── step-1-manifest.json      # GPU compute time & cost manifest
├── public/
│   └── models/
│       ├── index.json            # Model catalogue index consumed by Studio UI
│       └── [model]/
│           ├── art.jpeg          # Chosen 2D reference art
│           ├── model.glb         # 3D model rendered by three.js
│           └── manifest.json     # Aggregated lifecycle manifest
└── scripts/
    ├── common/
    │   ├── workspace-paths.ts    # Canonical workspace and model path resolver
    │   ├── pipeline-config.ts    # Strict typed loader for pipeline.json
    │   ├── gemini-client.ts      # Multimodal Gemini 2.5 Flash client
    │   ├── image-cropper.ts      # Node canvas grid cell cropper
    │   ├── manifest-manager.ts   # Per-step and aggregate JSON manifest manager
    │   └── stage-reporter.ts     # Visual ASCII terminal progress & tables
    ├── stage-0/
    │   ├── step-1-alternatives.ts# 3x2 alternatives grid generator
    │   └── step-2-pick.ts        # Interactive or automated cell selector
    ├── stage-1/
    │   └── step-1-trellis.ts     # RunPod remote GPU 3D synthesis client
    ├── server.ts                 # Local HTTP API server (port 4502)
    └── stage-orchestrator.ts     # Unified CLI stage runner
```

## ⚙️ Configuration: `pipeline.json`

Every prompt, system instruction, maturity progression, aspect ratio, image dimension, and GPU endpoint is declared in [`pipeline.json`](./pipeline.json). No hardcoded prompts exist in TypeScript code.

### Pipeline Stages Definition

1. **Stage 0: Art Alternatives & Selection**
   * **Step 1 (`s0-step-1`)**: `scripts/stage-0/step-1-alternatives.ts`
     * Input: Prompt description + up to 3 optional photo references.
     * Model: `gemini-2.5-flash-image` (aspect ratio 3:2, 2048x1365).
     * Output: `step-1-alternatives.jpeg` (3 columns x 2 rows grid).
     * Style Progression: 6 cells arranged from childlike/chibi (cell 1) to mature/realistic papercraft (cell 6), all sharing a clean 3/4 axonometric perspective on a neutral `#E5E5E5` backdrop.
   * **Step 2 (`s0-step-2`)**: `scripts/stage-0/step-2-pick.ts`
     * Input: `step-1-alternatives.jpeg` + cell number (`1..6`).
     * Output: `resources/<model>/stage-0/step-1-art.jpeg` and `public/models/<model>/art.jpeg`.

2. **Stage 1: 3D Model Generation**
   * **Step 1 (`s1-step-1`)**: `scripts/stage-1/step-1-trellis.ts`
     * Input: `resources/<model>/stage-0/step-1-art.jpeg`.
     * Service: Remote Microsoft TRELLIS server on RunPod GPU (NVIDIA RTX PRO 4500 Blackwell Server Edition, 32GB VRAM).
     * Parameters: `simplify: 0.95`, `texture_size: 1024`, `seed: 1`.
     * Performance: ~18–25 seconds per model, cost ~$0.003 USD per run.
     * Output: `resources/<model>/stage-1/step-1-3d.glb`, `public/models/<model>/model.glb`, and `manifest.json`.

## 🚀 Execution Commands

All stages and steps are executed through Nx (`nx run papikapi-studio:...`):

```bash
# Run Stage 0 Step 1 (generate 3x2 alternatives grid for a subject)
nx run papikapi-studio:stage:0:step:1 --model=cheetah --ref=resources/cheetah/stage-0/step-1-art.jpeg --prompt="A cute baby cheetah cub sitting down, identical pose and spots, clean low-poly papercraft facets without black crease lines"

# Run Stage 0 Step 2 (pick cell 4 as final art)
nx run papikapi-studio:stage:0:step:2 --model=cheetah --pick=4

# Run Stage 1 Step 1 (synthesize 3D mesh via RunPod GPU)
nx run papikapi-studio:stage:1:step:1 --model=cheetah

# Run complete Stage 0 or Stage 1 for a model
nx run papikapi-studio:stage:0 --model=cheetah
nx run papikapi-studio:stage:1 --model=cheetah

# Process all discovered models across Stage 1
nx run papikapi-studio:stage:1
```

### Local API Server for Studio UI

```bash
# Start backend API bridge on port 4502
npx tsx apps/papikapi-studio/scripts/server.ts

# In a separate terminal, launch the Angular Studio
npm start -- papikapi-studio
```

The Studio UI proxies `/api` requests to `http://localhost:4502`:
* `POST /api/creator/generate`: Generates the 3x2 alternatives grid.
* `POST /api/creator/pick`: Crops the chosen figure and triggers automatic 3D TRELLIS generation.
* `GET /api/health`: Health status of the local server and remote RunPod GPU.
